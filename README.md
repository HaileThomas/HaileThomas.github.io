# Thomas Haile — Personal Website

Source for [cs.stanford.edu/~tghaile](https://cs.stanford.edu/~tghaile/), built with Jekyll using the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme.

## Editing

- Site info, links and images: `_config.yml`
- Page content: `index.md`
- Experience: `_data/experience.yml`
- Publications: `_data/publications.yml` (the section is hidden while empty)

## Local preview

```sh
bundle install
bundle exec jekyll serve
```
